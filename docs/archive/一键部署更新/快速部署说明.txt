白龙桌宠 0.7.2｜一键快速部署

原项目来源：https://github.com/jingh12312-rgb/bailong-desktop-pet
本包为原白龙桌宠基础上的本地增强版，保留原素材说明。当前功能见“新增功能说明.txt”，已替换方案见“迭代历史.txt”。

使用方法
1. 完整解压本包；本版按用户要求不再提供分卷。
2. 双击“白龙桌宠-0.7.2-一键部署.exe”。无需逐项点击安装或启动，无需 Python 或管理员权限。
3. 程序会自动关闭已安装的增强版桌宠，安装或升级，校验载荷并启动候选版本，确认窗口和本地服务就绪后更新快捷方式。部署窗口完成后自动关闭。
4. 新电脑使用自己的 Codex 登录。未安装 Codex 时先安装并登录，在 Codex 中发送一次消息；桌宠会自动识别并接入。无需重启 Codex。

部署保留规则
- 已有设置、角色偏好、闲聊记录、密钥和本机 Token 数据保留在当前用户目录。
- 新安装默认开启 Windows 登录自启；升级保留已有自启开关，之后可在设置 → 常规中修改。
- 旧程序版本保留，仍可回退。
- 部署期间请保持窗口运行。失败时显示原因并提供重试；安装失败会恢复旧入口并尝试重新启动原桌宠。意外中断后，下次安装会先处理恢复记录。
- 只操作本用户安装记录内的白龙增强版进程，不结束 Codex、浏览器或其他 Python 程序。

连接与其他功能
桌宠自动发现本机 Codex CLI、会话日志和账户额度；首次统计在后台完成。上下文压缩与等待输入/审批状态通过 Codex 桌面版本机实时通道读取，正常气泡点击会话名通过 codex://threads/ 会话链接跳转。无需改动 Codex 配置。
进入设置 → 连接 → 检测连接与额度，可查看六项能力的独立健康状态；展开“连接路径与检测报告”可查看详细报告或选择数据目录、CLI。界面保存路径需验证并重启桌宠后生效；环境变量优先，不修改 Codex 配置或登录凭据。
独立闲聊需要配置自己的模型服务、地址、模型和密钥；本地服务与 Windows 加密密钥不会随安装包跨电脑迁移。
Token 范围是本机可读日志；额度依赖本机 Codex 有效登录；额外重置公告需要联网访问 Codex Resets。

回退和卸载
双击本包“安装管理.cmd”，打开普通安装维护界面，可回退或卸载，不会自动再次部署。
安装目录中的“白龙安装管理.exe”和系统应用卸载入口也可进入维护界面。
卸载保留用户配置与聊天记录。回退后退出正在运行的桌宠，再使用快捷方式启动。

白龙桌宠增强版 v0.7.2｜持续状态响应优化（UI61）
原项目来源：https://github.com/jingh12312-rgb/bailong-desktop-pet

思考、阅读、编辑、执行、检查等工作状态使用对应工作动作定期续播，不再共用装饰动作的60秒重复冷却。默认检查间隔由18秒调整为12秒；已有非默认间隔保留，已经采用新规则后手动设回18秒也会保留。
工作动作完整播完后至少停顿2秒，用户设置更长动作间隔时遵从用户设置。手动动作、拖拽、移动、普通随机互动、装饰动作的优先级和保护不变。不是每条状态都立即切换，也不抢断当前动作。
长时间没有文字更新时，通过已连接Codex的实时回合元数据每15秒确认任务仍在进行；只延续对应会话和回合，不重发状态文字、不滚动气泡、不重复收到任务动作。确认35秒失效、原状态也超过90秒时不再继续旧动作。Codex关闭、任务终止或等待用户操作时不持续工作。IPC断开或协议不兼容时回退到现有有时效的日志状态，不永久认定任务活跃。
完成提醒保持及时显示、待查看常驻和已读确认；庆祝等待动作安全边界，并继续拥有视频全屏让位的提醒优先级。自动状态动作不播放声音。原25段素材、人物大小和过渡像素不变。
