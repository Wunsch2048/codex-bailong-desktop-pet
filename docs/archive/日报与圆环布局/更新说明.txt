白龙桌宠 0.6.18 · Token 日报与布局

日报默认隐藏，点击气泡右上角“纸页柱状图”按钮打开，再点或点日报右上角关闭按钮收起。日报独立浮在气泡正上方，两侧宽度对齐；展开/收起采用 260ms 缓动，不使用透明度叠加；概览和模型页保持同一高度，空间不足时内部滚动。
日报打开时暂停自由行走，窗口随气泡定位。聊天/设置打开、桌宠隐藏时收起日报，不自动弹出。

概览没有时间筛选。会话数、活跃天数、最常用模型、Token 总量统计全部已记录用量；会话按有 Token 记录的本机会话标识去重（含子任务），最常用模型按 Token 总量排序。消息数、高峰时段和 24 小时消耗曲线汇总本地时间前一日 00:00–24:00，不是滚动 24 小时，也不把累计计数当成小时消耗。
原方格日历由前一日小时曲线替换。小说用量对比句直接用累计 Token / 100,000 动态计算，标为“约”，并明确每本 10 万 Token 的等量估算假设，不声称实际书籍或模型的固定分词数。

模型页保留“全部 / 30天 / 7天”，范围截至昨日日末；柱图按模型堆叠，列表列出各模型总量、占比和可用的输入/输出分项。点击某模型只显示该模型，再点恢复；缺少模型标记时显示“未识别模型”，分项不完整时不编造 in/out 数值。

索引升级保留原 Token 总量与全局去重指纹，补录日志中的模型、会话和公开消息元数据。只保存标识、时间、计数和消息哈希，不保存对话正文、工具输出或隐藏思考。缺失原日志的旧累计记录保留，标记元数据不完整。输入计数已含缓存、输出计数已含推理，不再次相加。
首次补录与后续统计由独立后台线程执行，不阻塞 Codex 状态监听和界面。状态监听、消息滚动、气泡过渡、人物动作、未读完成提醒等继续沿用现有逻辑。
