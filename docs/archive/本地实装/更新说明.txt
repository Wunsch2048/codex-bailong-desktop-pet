v0.8.3｜额外重置显示小时与分钟

额外重置剩余时间改为小时、分钟组合。正常小卡片使用“12时30分”紧凑排版，详情显示“12小时30分钟”；不足一小时显示分钟。分钟向上取整，整小时显示00分，每分钟原位更新；到期仍等待公告确认。保留卡片尺寸、隐藏停表、原公告优先规则与已读提醒修复。

重置小卡片右上角补回公告网站跳转按钮。点击图标直接打开Codex Resets，点击倒计时区域仍打开本地公告详情；详情中的来源链接保留。

修复“会话待查看”无法自动消除：确认会话已读后，精确匹配已经结束的旧轮次（含失败、中断），不再被同会话的新一轮任务挡住。保留4秒稳定确认及其他会话的未读提醒；尚在进行、缺失或未知状态的轮次不会自动确认。

v0.8.1｜胶囊快捷功能与 Codex 同步启动（此前本地先行迭代，随 v0.8.3 公开）

胶囊左侧圆形按钮可在设置 → 常规与外观选择功能：GPT 网页、打开 Codex、白龙闲聊、数据日报、刷新全部数据、设置、自定义网页。缺省为 GPT 网页，使用系统默认浏览器。自定义只接受 http/https 地址；图标、辅助名称随功能改变，刷新保留忙碌与结果动效。

新增“打开 Codex 时自动启动桌宠”：开启后登录 Windows 时仅运行轻量监听，每2秒检查一次桌面端主进程。排除 Electron 子进程、Codex CLI 和 ChatGPT-only 应用；兼容官方安装及保留包路径的 Codex++ 托管副本。桌宠已运行时不重新展开卡片。手动退出桌宠后，当前 Codex 会话不反复拉起；关闭后重新打开 Codex 再触发。关闭 Codex 不强制退出桌宠。

“登录 Windows 时启动”与启动联动为独立开关。若只希望随 Codex 启动，关闭前一项，仅保留联动。无需管理员权限、修改 Codex 安装或安装 Codex++。首次启用时 Codex 已打开，会立即补启动一次。

升级和兼容版本回退会更新联动入口；回退到0.8.0等不支持联动的版本会停用监听入口，偏好仍留存供升级后恢复。卸载会关闭监听。数据与回退沿用原安装事务。该功能已随 v0.8.3 公开。
