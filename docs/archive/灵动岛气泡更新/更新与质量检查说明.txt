白龙桌宠 0.6.20 · 灵动岛气泡、自动模式与图表入场

模式：原版模式保留 268px 气泡、完整状态、额度环、Token 卡片及详情入口；90 秒没有真正的 Codex 状态/完成事件，或发现 Codex 桌面应用关闭后，自动收成 267×44px 的短胶囊。收到任务更新自动恢复原版。额度、Token、公告轮询不刷新空闲时钟。显式打开的聊天/设置/详情/日报不会被自动收起。
原版右上角的胶囊图标固定为缩小模式。缩小态保留简短 Codex 状态、完成提醒图标，周围三个独立圆形分别是闲聊、额度和模式切换。模式圆切回原版；显式切回后有 15 秒操作宽限。固定缩小模式收到状态也不会展开；模式选择保存到设置。点击胶囊/额度可主动查看详情。

额度：存在可用五小时额度时优先五小时；五小时为 0 且有周额度时显示周额度；五小时重置到期先切回五小时、显示 — 并查询，等新额度返回后再显示真实百分比。未知和已过期数据不会伪装为 0 或 100%。圆环宽 4.5px，数字不做虚假计数动画。
Codex 是否运行在独立低频线程每 5 秒检查，按 OpenAI.Codex 应用包 GUI 进程识别，后台 CLI 不当成桌面应用；权限不明保留未知状态。该查询不阻塞状态尾读及 Token 统计。

配色评估：瓷白 #fcfafc，主文字 #393343，次文字 #706879，低彩度紫 #8b78a6，深梅灰胶囊 #302a3c，胶囊文字 #f7f3fb。以白龙的冷白、浅紫为基调，少量低彩度灰蓝/灰绿/玫瑰色/米褐区分模型与警示。正文/次文字和胶囊文字对背景对比度均 >=4.5；主进度色对瓷白 >=3。禁用项和装饰轨道不承担正文信息。设置、聊天、详情、日报、图表及状态图标统一检查。

过渡：所有显式窗口展开/收回改成固定原生画布内绘制，动画帧不改变原生窗口尺寸、坐标或句柄。通过底部锚定的圆角裁切与图像内的轻量内容衔接呈现形变，不拉伸文字、不对真实窗口做透明度淡入淡出。真实控件隐藏一次，末尾恢复；预先处理嵌套布局与滚动条，避免完成后挤动。快速导航只保留最新请求，当前过渡完成后衔接。静止时释放过渡截图。
日报沿用固定画布裁切；原版状态文字与一/两行高度继续共享 300ms 时间轴；显式面板形变 280ms。隐藏即停止动画。

图表：面板展开后额度轨迹从 0 填到真实位置；柱状图从基线升起；小时曲线从时间轴起点沿真实折线逐步绘出，追踪点随曲线前进；日报模型柱状图、日期筛选及缩小额度环同样支持一次性入场。图表 620ms、额度环 420ms，使用 OutCubic；数字/坐标轴保持稳定。常规状态、额度、统计刷新不会反复从 0 播放；图表重绘会承接现有入场进度；隐藏后停止，不增加待机轮询。

验证：113 项既有和新增相关检查通过，之后追加的入场承接与折线轨迹检查也已通过。Windows 100% 与 150% 原生窗口逐帧验证覆盖原版/缩小、详情、聊天、设置和日报。面板形变帧内无 Resize/Move/Hide/Show；普通模式与缩小模式均保留窗口句柄。首轮原生动画计时约 16ms 中位帧间隔；该值是本机计时采样，并非对显示器实际呈现帧率的保证。详见验收目录逐项记录与 GIF。
