白龙桌宠增强版 0.6.25｜快速部署说明（Windows x64）
整理日期：2026-10-18

项目来源
原项目：https://github.com/jingh12312-rgb/bailong-desktop-pet
本包是在原白龙桌宠 0.3.3 基础上迭代的本地增强版。新增内容见“新增功能说明.txt”，旧方案和已替换内容见“迭代历史.txt”。原项目素材说明随包保留；项目链接和本地增强不改变原素材授权。

一、第一次安装
1. 先把 ZIP 完整解压到一个文件夹，不要在压缩包预览中直接运行。
2. 双击“白龙桌宠-0.6.25-安装程序.exe”，点击“安装 / 升级”。无需管理员权限，无需另装 Python 或字体。
3. 按需勾选“登录 Windows 时自动启动”。安装完成后点击“启动桌宠”，以后可从桌面快捷方式启动。
4. 基础桌宠和本地动作可以独立使用。要启用 Codex 联动，请在这台电脑安装并打开 Codex，用自己的账号登录并发送一次消息。
5. 桌宠会自动寻找本机 Codex CLI 和会话目录。首次 Token 索引在后台进行，等待统计完成即可。
安装、启动桌宠不需要重启 Codex。

二、升级、回退与卸载
升级前请先从托盘退出旧桌宠，再运行本安装程序。升级保留当前用户的数据，并保留旧程序版本供回退。
安装管理器提供“回退到上一安装版本”和“卸载程序（保留配置与聊天记录）”。回退后退出旧进程，再从快捷方式打开。
不要把另一个电脑的登录凭据、API 密钥或用户数据目录复制过来。

三、Codex 连接检查
可进入：桌宠设置 → 连接 → 一键检测 Codex 连接。
也可在安装后双击本目录“检查Codex连接.cmd”。它会调用已安装的桌宠进行检查并展示结果。
报告位置：%LOCALAPPDATA%\BailongEnhanced\codex-connection-check.json
检测覆盖 Codex 识别、CLI、会话日志、额度和已读适配情况；不会替用户发送任务或消耗重置次数。

四、各项功能需要什么
- Codex 实时状态、完成提醒、Token 图表和日报：这台电脑需要有 Codex 本地会话日志；统计范围只覆盖本机可读日志。
- 账户五小时/周额度与重置时间：这台电脑的 Codex 登录有效，网络可用。只显示账户实际返回的窗口；临时未知不当作 0% 或 100%。
- 看过回复后自动清除提醒：需要识别到当前 Codex 版本的本地已读标记和匹配轮次，稳定确认约 4 秒后清除；不能识别时仍可点击图标手动确认。
- 额外重置消息：需要访问 Codex Resets。站点公告不等于个人额度已经到账。
- 独立闲聊：在聊天界面配置自己的 OpenAI 兼容服务、API 地址、模型及密钥。本机 localhost 服务不会随安装包迁移；Windows 加密的密钥不能跨电脑直接使用。

五、常用入口
- 右键人物或托盘：设置、动作、桌面控制、登录自启、退出。
- 气泡顶部刷新：查询账户额度；右侧 Token/公告卡提供相应刷新入口。
- 日报按钮：在气泡上方打开或收回日报，查看概览或模型统计。
- 正常模式右上胶囊按钮：固定缩小；缩小模式最右圆形按钮：回到自动正常模式。
- 自动模式在长时间无任务更新或 Codex 关闭后收起，新状态到来恢复。固定缩小模式由用户手动切换。编辑设置、聊天或查看详情/日报时保持界面。
- 最多显示两个会话，更多会话通过 +N 切换；对话名在左侧固定，操作摘要各自滚动。

六、特殊路径与故障排查
自定义 Codex 数据目录：设置 CODEX_HOME，也兼容 BAILONG_CODEX_HOME。
特殊 CLI 路径：设置 BAILONG_CODEX 指向真正的 CLI codex.exe。设定后重启桌宠即可。
商店版 Codex 的 GUI 主程序 app\Codex.exe 不是 CLI；桌宠会自动寻找 resources\codex.exe 或本机 CLI 缓存。

查不到状态：确认这台电脑已在 Codex 中发过消息，再运行连接检测。
查不到额度：确认本机 Codex 已登录且可联网，然后点击额度刷新。
没有出现人物：检查托盘入口并选择恢复显示/关闭穿透，或在设置中回到当前屏幕右下角。
只玩桌宠时，上述 Codex 连接条件不影响本地人物和动作。

七、文件位置与携带范围
程序：%LOCALAPPDATA%\Programs\BailongEnhanced
配置、聊天记录和本地统计：%LOCALAPPDATA%\BailongEnhanced
新机器只需携带并解压本安装压缩包，使用新机器自己的 Codex 登录和记录。
包内不包含此电脑的账号凭据、密钥、聊天内容、任务文本或 Token 数据库。
适用 Windows x64；已在 Windows 11 验证。未声称在其他实体电脑或其他系统上完成实测。
SHA256.json 可用于核对包内文件是否完整。
