# v1.0.0-linux-preview.1

本 fork 的首个 Linux 预览版，面向 CachyOS/Arch x86_64、niri 原生 Wayland。基于上游 v1.0.0，Windows 入口与 app 源码保持不变。

## Linux 适配

- 使用本机 Codex Unix IPC、会话日志和只读 SQLite，显示真实任务、额度和 Token；重置公告沿用原查询线程
- 原生拖动、自由走动、气泡跟随、屏幕边界、拖动打断和位置持久化
- 分离气泡、设置/聊天面板、Token 日报及过渡画布定位，保留原组件与动画绘制；缩放保持脚底锚点
- 独立 Linux/PyCharm 启动入口，无验证时限，不修改系统 Python、全局 GTK 主题或 Codex 配置
- 同一构建提供便携 tar.zst 和 AppImage，包含 Python 3.12、Qt 与轻量素材

## 安装与使用

AppImage 赋予执行权限后运行；便携包解压后运行 AppRun。详见 [使用说明](../LINUX_PACKAGE.md)。首次使用需准备 niri 桌宠窗口规则；规则采用本机的 background-effect 扩展，其他 niri 构建需验证兼容性。宿主需 bubblewrap、本机 Codex 和 niri/Wayland。

默认设置位置为 `${XDG_DATA_HOME:-~/.local/share}/codex-bailong/BailongEnhanced`，切换源码版/便携版/AppImage 前退出旧实例。发布包不包含用户设置、凭据、日志或会话。

## 验证范围

- 发布前 70 项针对性测试通过，其中 21 项 Linux 适配测试、49 项公告与刷新测试
- 构建前校验完整素材 SHA256；归档解压后校验 277 个普通载荷文件
- 隐藏源码目录及其中虚拟环境后，便携程序和 AppImage 解压运行成功；AppImage 正常 FUSE 挂载启动也通过
- 真实额度查询、Token、任务读取和 IPC 连接通过；IPC 健康快照曾短暂 degraded，不声称压缩任务全过程已验收
- 便携程序移动后保存位置，AppImage 两种运行方式恢复到同一显示器和位置
- 三轮正常退出，退出码 0、状态锁释放；日常设置和 Codex config.toml/auth.json 前后哈希一致
- 面板稳定位置误差约 0–1 逻辑像素，用户已初步验收 GUI；未做完整高 DPI、其他发行版或长期运行验收
- 原面板测试曾有两项 test_bubble_resize 锚点测试失败（未安装 Linux 适配），不能宣称上游全套测试通过

## 预览版限制

随机动作、解说及声音仍默认强制关闭。Codex 会话跳转、聊天密钥保存、Linux 自启动、随 Codex 启停、声音播放、甩出惯性和 Windows 更新安装流程尚未适配；部分 UI 入口仍保留。透明区域命中、置顶、通知和完整跨屏行为还需完善。请不要使用 Windows 安装器更新此 Linux 包。

本次不发布新的 Windows 产物。素材与第三方组件沿用仓库 NOTICE.md 及随包授权说明。
