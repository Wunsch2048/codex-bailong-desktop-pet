# v1.0.0-linux-preview.2

基于上游 Windows v1.0.0 的第二个 Linux 预览版。提供 x86_64 便携 tar.zst、AppImage 和 SHA256SUMS.txt；不发布 Windows 安装包，也不修改 app/ 或 Windows 入口。

## 本次更新

- 合入 KDE Plasma X11/XWayland 后端，通用入口自动识别 KDE 或 niri。
- niri 与 KDE 人物透明区域统一按 alpha >= 12 接收点击；保留原画边缘与拖动交接。
- 设置中的“开机启动”接入 systemd 用户服务，登录图形桌面后启动桌宠。
- “随 Codex 启动”使用独立的轻量监听服务，不依赖“开机启动”开关。关闭开机启动仍可随 Codex 启动；同一 Codex 会话手动退出桌宠后不反复拉起。
- 关闭监听不会关闭已经启动的桌宠。“随 Codex 关闭”仍未实现。
- AppImage 自启动登记外部文件路径，保留真实 Codex 数据与原有位置、设置。

## 使用

下载后运行 `sha256sum -c SHA256SUMS.txt` 核对两个包。AppImage 赋予执行权限后运行，便携包解压后运行 AppRun。自启动需要 systemd 用户管理器和已导入图形会话环境；请先将程序放在固定位置，移动后重新关闭并开启相关启动开关。

宿主需要 bubblewrap 和本机 Codex。niri 还需桌宠窗口规则；详情见[使用说明](https://github.com/helantianshen/codex-bailong-desktop-pet/blob/v1.0.0-linux-preview.2/docs/LINUX_PACKAGE.md)。默认数据目录沿用 `${XDG_DATA_HOME:-~/.local/share}/codex-bailong/BailongEnhanced`，升级前退出旧桌宠，替换程序文件即可。安装包不包含用户凭据、会话或设置。

## 验证与限制

本版发布前重新执行 108 项 Linux 适配及共享数据回归、工作流语法检查。完整素材及解包后 279 个载荷文件逐项验证 SHA256。便携包与 AppImage 解压模式在隐藏源码目录后运行，验证真实 IPC、额度、Token、位置保存恢复及退出锁释放；AppImage 普通挂载启动和冻结监听入口另做本机检查。

本机构建和包体运行环境为 CachyOS x86_64/niri；包含 Python 3.12、Qt 和轻量素材，不安装系统 Python 包。KDE 源码的既有验收见 KDE.md，本次未重新进行 KDE 安装包、GNOME、其他发行版、注销登录或长期稳定性验收。不是所有 Linux 通用包。

声音、随机动作、解说仍沿用入口关闭策略。会话跳转、聊天密钥保存、随 Codex 关闭、甩出惯性及 Windows 更新流程尚未适配。IPC 压缩状态曾显示 degraded，不宣称压缩全过程通过。Windows 生产代码未变，不等于做过 Windows 人工桌面验收。

本次冻结监听 5 秒短采样单核 CPU 2.2%、RSS 44.0 MiB，未加载 QtGui/QtWidgets；PyInstaller 会预载 QtCore。三个 GUI 启动样本单核 CPU 27.5–30.5%、RSS 226.7–363.3 MiB，属于启动与动画短采样，不代表长期平均。测试服务已清理，未启用用户日常自启动。Codex 配置、认证及日常桌宠设置哈希未变。
