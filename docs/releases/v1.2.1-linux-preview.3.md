# Linux 预览版 v1.2.1-linux-preview.3

第三个 Linux 预览版，同步上游 Windows v1.2.1。沿用原角色素材、GUI 样式和布局，Linux 适配独立实现，不改变 Windows 入口行为。本 Release 仅提供 Linux x86_64 便携包、AppImage 和 SHA256 校验文件，不提供 Windows 更新包。

## 已实现

### Codex 数据与联动

- 接入本机真实任务状态、额度、Token 用量和回复摘要。
- 支持 Token 日报、额度对比、账户重置时间及额外重置公告查询。
- 支持点击任务名称跳转对应 Codex 会话，以及唤起 Codex 窗口。
- 支持通过独立 systemd 用户服务设置“登录桌面后自启动”和“随 Codex 启动”，两个开关互不依赖。
- 已接入“随 Codex 关闭”：确认桌面主进程退出后关闭桌宠，仅关闭窗口但进程仍驻留时不会触发。

### 角色与界面

- 支持 niri 原生 Wayland，以及 KDE Plasma X11／XWayland 后端。
- 支持拖动、持续拎起动画、松手落地、自由走动、随机动作及人物缩放。
- niri 拖动期间气泡持续跟随，支持屏幕边缘定位和上下避让。
- 支持显示器与位置记忆，重启后恢复。
- 支持分离气泡、设置和聊天面板、日报，以及胶囊／普通／详情等界面切换。
- 支持透明区域点击穿透，人物点击区域采用 alpha ≥ 12。
- 支持顶栏悬停提示、托盘额度环、额度与重置时间提示。
- 修复托盘菜单首次显示不完整、再次出现空白的问题。
- 统一托盘与胶囊打开设置后的拖动跟随和边缘避让行为。

### 运行与数据保存

- 提供便携包与 AppImage，无需向系统 Python 安装依赖。
- 桌宠设置、位置及统计索引存放在独立 XDG 数据目录，替换程序文件时可继续保留。
- 额度查询通过 bubblewrap 隔离，原 Codex 配置与认证文件只读访问。
- 正式入口没有验证时限，支持单实例检查和正常退出。

## 已实现但有限制／仍需进一步验收

- **拖动交接**：松手后约需 700ms 才交回可点击气泡，期间继续显示跟随画面。
- **特殊布局**：隐藏角色或气泡跨屏分离时，展开收起仍有额外窗口交接等待。
- **托盘提示样式**：由桌面原生托盘展示，外观随桌面主题变化。
- **自由走动动画**：当前素材没有独立走路动画，沿用原逻辑回退到拎起动画。
- **KDE**：已有后端及此前实机验证，本次更新后的完整交互仍需复验。
- **随 Codex 关闭**：已通过受控进程退出测试，尚未完成关闭真实 Codex 的完整人工验收。
- 多屏热插拔、全部缩放组合、系统通知、跨桌面置顶效果及长期稳定性尚未全面验收。

## 尚未实现或未完成适配

- 声音播放：Linux 启动时仍关闭声音。
- 聊天密钥安全保存及完整联网聊天流程；聊天页面可打开不代表该能力已可用。
- niri 拖动松手后的甩出惯性。
- Windows 式视频／游戏全屏识别与自动让位；全屏窗口可以覆盖桌宠。
- Linux 应用内程序更新、安装回退及程序目录迁移；请勿使用 Windows 更新包。
- GNOME、其他 Wayland 合成器及其他架构的专用适配。
- 素材迁移、更新与回退的完整 Linux 实机验收。

## 安装与更新

- AppImage：赋予执行权限后运行；无法使用 FUSE 时可添加 `--appimage-extract-and-run`。
- 便携 tar.zst：解压后执行目录内的 `./AppRun`。
- 用附件 `SHA256SUMS.txt` 校验下载文件。先退出旧实例，再替换程序；设置与位置保存在 `${XDG_DATA_HOME:-~/.local/share}/codex-bailong/BailongEnhanced`。
- 首次升级会开启此前被入口关闭的随机动作和回复摘要，之后尊重各自保存的开关；声音保持关闭。
- 开启自启动后请保持程序路径固定。更换 AppImage 或便携目录路径后，关闭并重新开启相应自启动开关，以更新 systemd 路径。

## 环境说明

主要验收环境为 CachyOS／Arch 系 x86_64 + niri。KDE Wayland 会话通过 XWayland 运行，尚非原生 Wayland 后端。

宿主需要 bubblewrap；会话跳转需要 xdg-utils 和有效的 codex:// 协议注册。niri 需按说明配置桌宠窗口规则，包内规则含本机 niri 的 background-effect 扩展，其他构建需检查兼容性。当前支持范围不代表所有 Linux 发行版与桌面环境均已兼容。

## 本次验证

- 源码 126 项相关回归通过，GitHub Windows/Linux Source checks 通过。
- 便携包与 AppImage 解压运行在两个源码目录均被隐藏的条件下启动，核对真实 IPC、额度与 Token；便携包移动保存后，AppImage 恢复同一显示器和位置，均正常退出并释放状态锁。AppImage 直接挂载启动也通过；验证中受用户手动移动干扰的两次位置断言不计为通过，停止干预后复验通过。
- 279 个载荷文件逐项 SHA-256 校验通过；素材、TLS 与真实只读额度自检通过。Codex 配置、认证及日常桌宠设置哈希未变。
- 三次成功 GUI 启动短采样单核 CPU 为 21.5–26.0%、RSS 为 207.3–217.7 MiB，仅代表采样窗口，不代表长期平均；未做主线程阻塞或磁盘 I/O 专项测量。
- 新包未在 KDE、GNOME 或其他发行版进行实机验收；UI 人工验收来自本机同版源码，自动启动与坐标检查不能替代完整视觉回归。
