# Linux 预览版 v1.4.2-linux-preview.5

第五个 Linux 预览版，程序基于上游 **1.4.2**，合入 KDE 维护者 FarnaHerry 的 [PR #3](https://github.com/helantianshen/codex-bailong-desktop-pet/pull/3)。本版提供 Linux x86_64 的 AppImage、便携 tar.zst 和 `SHA256SUMS.txt`。程序内版本显示为 `1.4.2`，预览后缀用于区分 Linux 交付批次。

## 相比 preview.4 的变化

- 同步上游 1.3.0 至 1.4.2 的状态、聊天、设置和说明页，以及下载重试、素材识别和恢复修复。保留共享界面的样式与布局。
- 包内轻量素材更新为 45 个文件、35 个动作，包含独立走路动画。已有完整素材可继续使用，缺失内容由素材页主动补齐；保存的高清、仅卡片和隐藏人物选项保持不变。
- 修复 niri 连续展开/收起时的透明缺块、绘图报错、提示位置延迟，以及人物拖动松手后卡片错位回跳。面板在人物拖动后回普通状态卡的规则继续与上游一致。
- 修复 KDE 动画换帧后鼠标命中区域仍沿用旧轮廓的问题。命中区域随当前帧、动作渲染缩放及偏移更新；同帧继续使用缓存。
- 升级不再因缺少迁移标记而开启用户已关闭的随机动作、回复摘要和自主走动。
- Linux 维护页只提供程序下载入口和兼容动画更新。Windows 程序包在检查、下载和实际安装入口均被拦截，动画仍核对最低程序版本与 SHA-256。
- “随 Codex 启动”遇到失败或超时后，同一 Codex 会话不再反复启动桌宠；新会话或重新启用监听后可重试。
- 包内补齐 `NOTICE.md` 引用的原素材声明，方便离线查阅。

## 安装与更新

本版沿用 **CachyOS x86_64 本机构建与验收**，面向已更新的 CachyOS/Arch 系统。包内运行库要求 **glibc 2.44 或更高版本**，可运行 `getconf GNU_LIBC_VERSION` 检查。包内包含 Python 3.12、Qt 6.9.2 和轻量素材，无需向系统 Python 安装依赖。支持 niri 原生 Wayland，以及 KDE Plasma X11 / XWayland；KDE 不需要 niri，KDE Wayland 会话须启用 XWayland。其他发行版的运行库兼容性仍需验证。

1. 下载 AppImage 或便携 tar.zst，并用同一 Release 的 `SHA256SUMS.txt` 校验所选文件。
2. 退出旧桌宠。AppImage 赋予执行权限后运行；便携包解压后执行 `./AppRun`。AppImage 无法使用 FUSE 时可加 `--appimage-extract-and-run`。
3. 保留 `${XDG_DATA_HOME:-~/.local/share}/codex-bailong/BailongEnhanced`。新旧两种包共用此数据目录，不要同时运行。
4. 启用自启动的用户应保持程序路径固定；若更换了路径，在新版中关闭并重新开启相应开关，更新 systemd 服务路径。

宿主需要本机 Codex 和 bubblewrap（`bwrap`）。会话跳转需要 xdg-utils 及有效的 `codex://` 协议注册。niri 需按[配置说明](https://github.com/helantianshen/codex-bailong-desktop-pet/blob/main/docs/LINUX.md#niri-专用窗口规则)设置窗口规则；包内规则包含 CachyOS niri 的 `background-effect` 扩展，其他构建需检查兼容性。本包不自动修改桌面配置。

升级通过手动替换 Linux 程序包完成，不使用上游 Windows 安装器或 Windows 更新附件。设置、统计索引及素材偏好保存在用户目录。额度查询通过 bubblewrap 只读访问 Codex 原配置与认证文件，交付包不含用户数据。

## 验证范围

- 按 Linux CI 清单执行 42 组、398 项用例，无失败；Windows 8.3 路径专项在 Linux 按平台跳过。[对应提交的 Windows/Linux CI](https://github.com/helantianshen/codex-bailong-desktop-pet/actions/runs/41384407095)通过。Linux 构建工作流另通过冻结程序的 xcb 窗口启动与退出检查。
- 本轮 niri 源码原生检查 50 个检查点通过，覆盖重复展开/收起、移动、切页、取消和提示定位。用户此前已确认同版功能源码的真实鼠标操作正常，日志无异常。
- 本次公开包在 CachyOS 本机构建。逐一核对 149 个冻结程序模块与源码一致、371 个包内文件的摘要，以及全部 45 个轻量素材的大小和 SHA-256。包体不含账号、会话、用户设置或 IDE 配置。
- 便携包与 AppImage 解压运行在源码目录被隐藏的环境中通过；AppImage 直接挂载在宿主通过。三种方式均验证真实 IPC、额度查询、HTTPS 公告查询、位置保存及跨格式恢复、保留关闭的行为开关、正常退出和状态锁释放。检查前后 Codex 配置、认证文件及日常桌宠设置保持不变。
- Token 已读取到真实数据，但本机存在无法完整识别的日志，状态为 `token_partial`；同一数据源在源码中也可复现。因此不将完整 Token 统计列为通过，也没有修改原日志。
- 三次启动后的 3 秒短采样，单核 CPU 为 15.3–18.0%，RSS 为 264.2–320.5 MiB；采样期间磁盘写入为 0–约 1.0 MiB。仅为本机短时样本，不代表长期平均、峰值或性能改善；未做主线程阻塞及隐藏状态长期空转专项。
- 用户确认 KDE 维护者已完成修复后的实机测试。本次新包没有新增 KDE 桌面实装验收；Xvfb 的 xcb 启动检查也不代替 KDE 真实鼠标交互。

## 保留的限制

- 继续作为社区预览版发布。支持范围不扩展到 GNOME、其他 Wayland 合成器、其他架构或所有 Linux 发行版。
- KDE 使用 X11/XWayland，没有原生 KDE Wayland 后端。维护者已测试合并后的 KDE 修复；本次新 AppImage/便携包的运行检查在 niri 完成，不把源码实测写成 KDE 包体安装验收。
- 声音仍关闭。聊天页面可打开，聊天密钥安全保存及完整联网聊天流程仍未适配。
- Linux 应用内程序更新、安装回退、程序目录迁移、沿前台窗口行走、niri 松手甩出惯性，以及 Windows 式视频/游戏全屏识别尚未适配。全屏窗口可以覆盖桌宠。
- 多屏热插拔、全部缩放组合、35 个动作的完整播放接缝、素材迁移/更新/回退全流程及长期稳定性未全面验收。
