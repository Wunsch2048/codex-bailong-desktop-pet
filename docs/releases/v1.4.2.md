# 白龙桌宠 v1.4.2：下载与人物素材补齐修复

本次是累计程序修复包，重点解决 v1.4.1 中“动画待补齐”却无法下载的问题，同时修复程序续传和首次安装器的重试问题。

## 人物动画无法补齐（#24）

1.4.1 的内嵌素材目录仍使用旧的 `materials-…` 下载地址，但当前完整动画实际已发布在 v1.3.0。旧地址返回 404，界面又将其误报为“尚未公开发布”，导致缺少部分素材的用户无法补齐。上一轮完整本地素材恢复的修复没有覆盖这一条真实下载路径，本次补上。

- 恢复轻量、高清动画正确的公开地址、归档大小和 SHA-256 信息。
- 构建与程序打包增加检查，缺少有效的动画下载信息时停止，不再悄悄带入旧地址。
- 内置轻量素材文件名齐全但文件被截断时，不再误判为就绪；通过独立缓存补齐，保留原文件。
- 没有当前素材或使用仅卡片模式时，素材页沿用保存的画质选择。
- 404 提示改为下载地址暂不可用，不再仅凭这个状态断言动画尚未发布。

**更新方法：**先更新本次累计程序，再进入“设置 → 素材”选择画质，点击“下载并启用”。已有文件经校验后可以复用，完整动画无需重新下载。人物动画仍沿用 v1.3.0 的两档资源；45 个文件对应 35 个动作，本次没有重新制作动画包。

## 程序下载与首次安装器

- 程序续传遇到服务器拒绝分段（HTTP 400、405、416）时，在同一地址回退一次完整下载，继续核对大小和 SHA-256，避免反复卡在同一断点。
- 更严格核验续传响应的起点、终点和总大小，异常时不追加错误字节。
- 区分版本查询失败与附件不可用；已经公开的版本，其附件返回 403、404 或 429 时，不再误报“暂无公开版本”或一律归因于 API 限流。
- 本次重新生成的在线安装器遇到损坏的已下载缓存时，可以重新获取并校验，不再让“重试”一直读取坏文件。只处理自身的无效下载缓存，保留安装和用户数据。

## 保留与验证

设置、统计、画质、人物/面板选择和旧版回退继续保留。下载失败或取消不切换到未通过校验的内容，已暂存的程序被改动时仍拒绝执行。

本地相关检查覆盖 16 个模块、194 项；在线安装器实际 C# 代码的 16 项受控检查通过。另以 45 文件的合成 WebP 素材回放首次启用、32 项旧文件复用、仅卡片重新启用、代理不支持分段和取消等 8 条路径。最终发布副本已通过137个模块、1514项完整回归、冻结源码绑定、TLS和四档原生交互检查，以及真实安装器暂存与仅卡片启动验收。两档动画地址从最终程序目录读取后核验。正式附件公开后另作匿名下载核验。

真实下载核验区分整包与分段：小型在线安装器可以整文件核对 SHA-256；程序、离线安装包和动画的大文件分段探针不作为整包重新下载的证明。旧版安全软件反馈仍单独跟踪，本次下载修复不代表检测已经解除。
