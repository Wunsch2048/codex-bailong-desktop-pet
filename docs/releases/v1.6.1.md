# v1.6.1

- **卡片防闪**：改善日报开合、正常卡片刷新和周额度悬停时的闪烁，保留原有展开速度和数字翻动。
- **面板联动**：从正常卡片进入设置或返回时，已打开的数据面板会随卡片变宽或收窄，标题、页签和内容一起过渡。
- **会话切换**：正常卡片和大卡片按会话数量翻页时，新行直接落在对应位置，避免重叠和从上方掉下来。
- **任务状态**：任务结束后，迟到的工具记录不会让已完成的会话重新显示忙碌，桌宠也能恢复自主走动。见 [#25](https://github.com/Wunsch2048/codex-bailong-desktop-pet/issues/25)。
- **Windows 兼容**：修复 Anaconda 等环境的同名 OpenSSL 文件干扰。随包文件缺失时会提示使用官方安装器修复。见 [#26](https://github.com/Wunsch2048/codex-bailong-desktop-pet/issues/26)。
- **实时窗口**：服务提示只看 Codex 相关状态，避免其他服务的事故触发提示。状态圆点也与文字对齐。
- **额度悬停**：灰色高亮覆盖整个模块，鼠标经过差异标记时高亮保持连续。

已有用户可在“设置 → 维护 → 软件更新”升级。首次安装下载本版本的 setup.exe。升级保留设置、历史统计和已下载动画，无需重新下载动画包。
