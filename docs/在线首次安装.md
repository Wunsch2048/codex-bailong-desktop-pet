# 在线首次安装

新用户下载小型在线安装器后，安装器直接下载最新兼容的累计程序包，再进入该版本的正常安装界面。程序包包含 Python/Qt 运行环境，无须先安装旧基包，也不用逐个安装历史补丁。人物动画仍在设置中按需下载。

在线安装器不内嵌旧主程序，固定从本仓库稳定版的 `releases/latest/download/program-channel.json` 读取程序指向。元数据明确版本、正式附件地址、字节数、SHA-256和安装协议；下载后复用已有清单、逐文件校验、安装互斥、目录选择、备份及回退交接。网络/协议/校验失败停止并允许重试，不自动启动旧程序。已装版本更新则阻止降级。网络和文件准备在后台线程执行，取消会停止下载。

在线入口已随 v1.3.0 公开，通道与所指累计程序均已核验匿名下载及 SHA-256。旧1.1.0安装器不会自动获得联网能力，请使用主页的新入口。此交付不代表杀软告警已确认解决。

## 首次发布新入口

1. 依现有规则计算公开版本，制作独立发布副本并完成发布所需检查。
2. `build_program_update.py` 生成程序 ZIP、JSON、`program-channel.json` 和校验清单。
3. 需要小型在线安装器时，在发布副本运行：

   ```powershell
   python tools/package_program_installer.py --online-only --program <累计程序ZIP> --version <公开版本> --destination <本次发布暂存目录> --icon app/branding/bailong.ico
   ```

   不加 `--online-only` 还会生成固定版本的离线兼容安装器与旧更新器使用的 windows-x64 ZIP。在线安装器自身不嵌入程序包，也不需要再附一份旧基包。

4. 同一稳定 Release 上传在线安装器、累计程序 ZIP/JSON、`program-channel.json`、SHA256SUMS。公开前核版本、清单、源码与附件一致；公开后匿名校验通道及其指向的程序 ZIP 可下载，校验值一致。
5. 最后更新 README 首次安装入口。可保留指向这份已公开小安装器的固定版本链接；后续它根据通道获取最新程序。不要把固定版本的离线安装器称作自动获取最新版的入口。

## 后续只发程序补丁

`build_program_update.py` 会自动重建通道。上传新的程序 ZIP/JSON、通道与校验清单即可，通常不用重发在线安装器，更不用重发动画。通道协议不兼容时才需要新安装器，并明确更新首次安装链接。

## 只发动画补丁

Latest 可能指向只有动画的发布，所以每次仍附带一份有效的 `program-channel.json`。从上一公开稳定版取得并验证该文件，使用：

```powershell
python build_animation_update.py <原有参数> --program-channel <上一公开程序通道>
```

这会沿用上一完整累计程序 ZIP 的版本、地址和哈希，通道不指向动画包，也不推测不存在的同版本程序 ZIP。若旧程序不足以满足动画的最低程序版本，打包入口拒绝继续，必须同时发布支持该动画的程序更新。程序与动画同批时自动采用本次程序通道。

不更新已经发布的旧版内容，不在通道中填写本地开发号或草稿附件地址，不删除仍被通道引用的公开程序附件。首次启用通道前的历史动画发布没有该附件；不能声称旧公开页面已兼容这套入口。

## 验证边界

本批已验证 Windows C# 编译及15项受控传输、最终离线安装器空目录准备与纯卡片启动，并核对公开最新通道及所指程序的匿名 HTTPS 下载、文件大小与SHA-256。没有以真实陌生机器、全套用户操作或杀软兼容性作保证；在线安装器GUI未在真实新机逐步验收。
