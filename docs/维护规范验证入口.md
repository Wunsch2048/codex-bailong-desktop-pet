# 维护规范的公开验证入口

这里说明如何在公开仓库复核[维护与防错规范](../维护与防错规范.md)和[动画制作规范](../动画制作规范.md)。开发机的专项录像、诊断、用户目录与部署回执不随源码上传；公开的源码和测试是复跑入口，不能代替对应机器、对应冻结包的实际验收。

## 动画快照与入场

成本页曾在目标更新被冻结时只抓到背景；日报柱线曾横向揭示整张位图，并在容器停稳后继续等待。相关修法包括目标正文准备、分层缓存、可见后启动及播放中合并后台快照。

- [正文快照与反向切页检查](../app/test_project_cost_motion.py)
- [日报图表响应检查](../app/test_report_chart_response.py)
- [日报容器与布局检查](../app/test_daily_report.py)
- [主卡与日报交接检查](../app/test_report_transition.py)
- [图表缓存及绘制实现](../app/rate_chart.py)

源码像素检查与自然时钟录像分别使用。验证冷／暖、两个方向、中途刷新、取消及用户受影响的缩放，不能用计时器频率或强行推进时钟证明物理帧率。

## 页面状态与设置保留

新访问、当次返回和后台刷新分别处理复位与保留，主题预览与保存状态分开；升级不覆盖合法旧偏好。

- [项目明细导航和性能政策](../app/test_presentation_policy.py)
- [项目成本可靠性](../app/test_project_cost_reliability.py)

隔离安装替身不是陌生机器完整GUI安装。复跑时使用独立用户目录，不能将演示配置写入真实设置。

- [项目成本与日志处理](../app/project_cost.py)

业务统计一致、结构完整性、可恢复备份和增长趋势分别检查。不要直接复制仍有写入的SQLite文件，不要在真实用户库上练习故障注入；维护失败应保留原库，原始Codex日志不属于索引清理范围。
