# v1.5.0 数据面板与桌宠交互更新

本次是从 Windows v1.4.2 起的累计更新。

## 项目成本

- 按项目、会话和回合逐层查看。会话优先显示 Codex 中的名称，回合直接列出非缓存输入、缓存输入和输出用量。重复打开回合会先复用已读明细，日志更新时在后台刷新。
- 支持按项目名或目录搜索、按时间范围和归档状态筛选，以及按成本或名称排序。Codex 临时会话集中在「未归属项目」，明细保留原目录；失去来源的历史用量集中在「未识别项目」。
- 计价设置支持搜索模型、分别编辑三类单价、恢复内置价，以及用 USD、CNY 或 HKD 显示金额。汇率可手动输入或自动获取。导出支持 CSV 和 JSON。
- 计价覆盖率可点开查看待定价用量。项目详情从会话切到费用构成时，先准备回到顶部的新页再播放过渡。

## 日报、额度与实时速率

- 日报、模型和额度的柱状图统一悬停窗样式。模型列表用圆角底和对勾标记筛选；额度图用柱顶小三角标记当前周期。
- 额度页并列展示两轮按各自用法估算的容量。混用模型或统计条件不同也能看到两轮估算，同条件样本足够时才显示涨跌。
- 实时模块悬停查看分会话速率，点击查看 OpenAI 公开服务状态。两种窗口首帧直接可见，减少入场闪烁；服务状态和本机速率分别统计。
- 改进晚到 Token 记录的速率归属和已索引用量的汇总。短时间内多条任务完成通知合并刷新额度，手动刷新仍可直接发起。

## 桌宠动作与性能

- 自主走动前收起随行卡片。走动中展开会先自然停下，空闲约 5 秒后收起并继续走。边缘散步可在屏幕四周选落点，也支持斜向移动。
- 随行胶囊与人物按 Windows 实际窗口顺序排列。拖拽合并密集鼠标事件，松手先提交最终位置；分离面板留在原位。
- 修正工作中自动动作台词的判定，主动点击桌宠仍可触发回应。
- 日报重开减少隐藏页布局和原生窗口准备，设置重开跳过重复回填，缓存动作段复用后台读取线程。已下载的动画素材可继续使用。

## 设置、安装与维护

- 修复「程序位置与安装管理」在新版安装结构下误报维护程序缺失的问题，并完善打开数据目录、导出诊断、设置备份和恢复的失败提示。
- 首次安装器遇到文件被安全软件拦截或移除时，会显示相应的错误提示，帮助在保护历史记录中核对。
- 已有用户可用「设置 → 维护 → 软件更新」升级。首次安装可使用在线安装器，也可下载 Windows x64 离线包。升级保留设置、统计和素材。
