# v1.5.0 更新说明

这次更新让项目花了多少 Token 更好查，额度变化更好看懂，桌宠拖动和卡片打开也更顺手。以下内容包含 Windows v1.4.2 之后的累计改动。

## 项目成本

- 在「数据面板 → 成本」里，先看项目的总用量和估算费用，再点进去看哪条会话、哪一轮对话用得多。会话会尽量显示 Codex 里熟悉的名字，刚看过的明细再次打开时可直接复用。
- 项目可以按名称或目录搜索，按时间、归档状态筛选，也能按费用或名称排序。Codex 自动创建的临时目录集中在「未归属项目」，还可以点进去看原目录；已找不到来源的历史用量放在「未识别项目」。
- 从右上角「⋯」进入计价设置，可以搜索模型，分别调整输入、缓存输入和输出单价，也可以恢复内置单价。金额可用美元、人民币或港币显示，汇率可手动输入或自动获取。统计可导出为 CSV 或 JSON。
- 点「计价覆盖率」能看还有哪些用量没算进金额。这里的费用是把本机 Token 用量按 API 单价换算出来的参考值，订阅费用以账单为准。

## 额度与速率

- 日报、模型和额度图表都能把鼠标移到柱子上看详细数字。点选模型后有对勾，额度图用柱顶小三角标出正在看的周期。
- 额度页会把这轮和上一轮的容量估算放在一起。混用不同模型时，两轮各按当时的用法估算；只有使用条件足够接近，才会额外显示涨跌百分比。
- 鼠标停在「实时」上可以看各条会话的速率，点击则打开 OpenAI 服务状态。两个窗口打开时直接显示，减少闪一下的情况。稍晚写入日志的 Token 也更容易归到正确的回合。
- 多个任务接连完成时会合并额度刷新，手动刷新照常可用。

## 桌宠与卡片

- 桌宠自己走动前会先收起随行卡片。走动时展开卡片，桌宠会先自然停下；大约 5 秒没有操作，就收起卡片继续走。边缘散步可以斜着穿过屏幕，在四周停留。
- 拖动时减少了重复移动窗口的工作，松手会用上最后的鼠标位置。分离的面板仍留在原处。随行胶囊会和人物一起经过其他窗口，减少一前一后的情况。
- 工作时减少桌宠自己冒出的动作台词，主动点它仍能得到回应。
- 减少了重新打开日报和设置时的准备工作，成本明细切页时先把新页准备好再切过去。重复播放已缓存的动作也更省后台开销，已有动画素材可以继续用。

## 安装与维护

- 修复了设置里「程序位置与安装管理」有时打不开的问题。打开数据目录、导出诊断、备份或恢复设置失败时，会说明哪里出了问题。
- 安装时如果文件被安全软件拦截或移除，提示会引导你去 Windows「保护历史记录」查看详情。
- 已安装的用户可从「设置 → 维护 → 软件更新」直接升级。第一次安装可以使用在线安装器，也可以下载 Windows x64 离线包。升级会保留设置、统计和已下载的动画。
