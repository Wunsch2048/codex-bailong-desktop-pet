# v1.5.0 数据面板与桌宠交互更新

## 数据面板

- 成本页按项目、会话、回合逐层查看。无项目的 Codex 临时会话单独归组，仍可追溯目录；缺少来源的历史用量保留在未识别项目。
- 计价设置支持搜索模型，分别编辑输入、缓存输入和输出单价。成本排序、计价覆盖率和项目详情切换更清楚。
- 日报、模型和额度图表使用一致的悬停窗。额度页并列展示两轮各按其用法计算的容量估算，条件相近才显示涨跌。
- 实时模块悬停查看会话速率，点击查看服务状态。打开窗口时首帧直接可见。

## 桌宠与性能

- 自主移动时，随行胶囊按 Windows 的实际窗口顺序跟随人物。拖拽合并密集指针事件，松手提交最终位置。
- 日报重开减少布局和原生窗口准备；设置重开跳过重复回填；已缓存的动画段复用后台读取线程。
- 延续上一版动画素材，已下载素材可继续使用。

## 安装与更新

已有用户可用「设置 → 维护 → 软件更新」升级。本版本为累计程序更新。首次安装可使用在线安装器；需要离线安装时，下载对应的 Windows x64 包。设置、统计和素材随升级保留。
