# v1.6.0

- **实时数字**：今日 Token 随日志增量更新，变化数位独立上翻；实时速率按升降翻动，优化数字间距和刷新开销。
- **自动价格**：支持自动更新 API 模型单价和官方 Credits 价表，保留历史价格及手动设置。
- **计价设置**：模型单价收进独立页面，外层集中显示价格更新和汇率入口。
- **额度对比**：混用模型时也能查看参考差异，以黄色标记区分；调整图表位置，让信息更容易看全。
- **任务提醒**：会话继续工作后自动撤销旧完成提醒，修复内部附属记录被误显示为额外会话的问题。
- **界面过渡**：统一状态、聊天和设置的默认高度，改善筛选栏和设置分区切换，修复首次展开页签跳变及日报展开时的背景闪块。
- **页面交互**：修复模型页重新打开不复位、说明按钮残留灰色和说明页高度变化，以及多处悬停提示的首帧和刷新闪烁。
- **实时窗口**：再次点击实时模块即可收起服务窗口，移除多余关闭按钮。

已有用户可在“设置 → 维护 → 软件更新”升级；首次安装下载本版本的 setup.exe。升级保留设置、历史统计和已下载动画，无需重新下载动画包。

成本仍为 API 等价估算，不是订阅实际扣费；黄色额度差异按各周期实际用法作参考。自动价表与手动单价分别保存。
